# 1. Product Purpose

The Ledger is an AI-powered music contract intelligence and education platform.

The platform is designed to help artists, parents, managers, and emerging music professionals better understand contracts before signing them.

Core concept:

Contract
→ AI Analysis
→ Plain-English Explanation
→ Risk Identification
→ Rights Analysis
→ Revenue Analysis
→ Questions for Legal Counsel
→ Education

The Ledger is an educational product and is not intended to replace professional legal advice.

# 5. Partially Implemented Production Features

## Real PDF/DOCX Document Extraction
Status: PARTIAL
Estimated completion: 30%

Current limitation:

The Contract Analyzer contains simulated file-upload/text-extraction behavior.

TXT/plain-text input can be processed, but PDF/DOCX binary documents do not yet have a complete production extraction pipeline.

Required production pipeline:

Upload
→ Validate file
→ Extract actual text
→ Clean/normalize text
→ Analyze actual contract
→ Validate AI response
→ Store analysis

This is a P0 production requirement.

2. IBM Bob development should occur on a separate branch.

3. Frontend development should use separate frontend branches.

4. Changes should be reviewed before merging into main.

6. Build/type/test verification should occur before merging.

7. Major architecture decisions should be documented.

8. Production-readiness percentages should only increase after implementation AND verification.
